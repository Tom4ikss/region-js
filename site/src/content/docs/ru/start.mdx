<div class="lead">

Регионы, `spawn` и каналы есть в d8, тестовой оболочке V8, собранной из этого форка. Получить её можно тремя способами: от «ничего не ставить» до своей сборки. После этого каждый пример с сайта запускается одной командой. Есть и Node.js с регионами: на Linux x64 её собирает из исходников `scripts/setup-node.sh`, запуск — `node --harmony-regions`.

</div>

## В браузере: Codespaces {/* #codespaces */}

Быстрее всего — ничего не ставить: [откройте репозиторий в GitHub Codespaces](https://codespaces.new/Tom4ikss/region-js?quickstart=1). Он сам скачает готовый d8 и откроет песочницу, где Ctrl+Shift+B (Cmd+Shift+B на Mac) запускает открытый файл.

## Готовый d8 {/* #prebuilt */}

На Linux x64 и в WSL2 `scripts/get-d8.sh` скачивает готовый d8 из последнего релиза, проверяет контрольную сумму и ставит его в `~/.local/bin/d8` и `v8-src/v8/out/release/d8`. `TAG=...` берёт его из другого релиза. Тот же d8 есть в образе контейнера:

```sh
$ docker run --rm -it ghcr.io/tom4ikss/region-js
```

Готовый d8 — release-сборка с включёнными внутренними проверками V8 (DCHECK).

## Своя сборка {/* #build */}

На macOS или чтобы менять движок, d8 собирают из форка. Нужны macOS или Linux (подойдёт и WSL2), git, Python 3, около 15 ГБ диска и терпение: V8 собирается долго. Скрипт `scripts/setup.sh` скачивает depot_tools и V8 на нужном коммите (`v8/BASE`), накладывает патч `v8/regions.patch` и собирает d8 с флагами из `v8/args.gn`:

```sh
$ scripts/setup.sh
$ scripts/run-tests.sh v8-src/v8/out/release/d8
```

`scripts/run-tests.sh` прогоняет каждый тест из `tests/` один раз. `scripts/test-variants.sh` прогоняет их под вариантами флагов V8, это занимает часы. `scripts/setup.sh tsan is_tsan=true` собирает d8 с другими аргументами gn в `out/tsan`, а `JOBS=8` ограничивает число параллельных задач сборки на машинах с небольшой памятью.

## Как запускать примеры {/* #examples */}

Примеры с этого сайта лежат в `site/examples/ru/`, и каждый запускается одной командой:

```sh
$ v8-src/v8/out/release/d8 --harmony-regions site/examples/ru/01-first-region.js
```

Первой строкой d8 напечатает предупреждение:

```text
V8 is running with experimental features enabled. Stability and security will suffer.
```

Это нормально: так d8 сообщает о любых экспериментальных флагах. Дальше идёт вывод примера, тот же, что на страницах сайта.

Примеры перезапускает скрипт `node site/scripts/run-examples.mjs`: он прогоняет их все в d8 и сохраняет свежий вывод рядом с ними, а сайт при сборке (`pnpm build` в `site/`) показывает этот вывод.

## Полезные флаги {/* #flags */}

- `--harmony-regions` — включает `Region`, `spawn`, `Channel` и литералы `#{...}` и `#[...]` ([подробнее](/region-js/ru/guide/#literals)). Без него их просто нет, а `#{` — синтаксическая ошибка. Прежний флаг `--harmony-region-literals` значит то же самое;
- `--module` — выполнить файл как модуль, чтобы писать `await` на верхнем уровне. Примеры, которым он нужен, начинаются со строки `// d8-flags: --module`;
- `--max-serializer-memory=4000` — поднимает лимит памяти, который d8 отводит сериализатору `postMessage` (в мегабайтах). Без него копия большого дерева в замерах упирается в лимит. Примеры сайта запускались с этим флагом;
- `--spin-wait-us=50` — сколько микросекунд поток, которому нечего делать, проверяет, не пришла ли работа, прежде чем уснуть. По умолчанию 50, `0` отключает ожидание. С ним запуск `spawn` и обмен сообщениями примерно втрое быстрее ([почему](/region-js/ru/inside/#fast-spawn));
- `--verify-heap` и `--expose-gc` — проверка кучи и функция `gc()`. Ими пользуются тесты в `tests/`.

## Редактор {/* #editor */}

Чтобы писать примеры с подсказками и проверками в редакторе, откройте в VS Code папку `playground/` и выполните в ней `npm install` ([«Редактор и линтеры»](/region-js/ru/tooling/)). Cmd+Shift+B (Ctrl+Shift+B) запускает открытый файл в d8.
