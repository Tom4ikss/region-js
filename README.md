# region-js

*Ownership regions for JavaScript: an experimental V8 fork with `spawn(fn)` for parallel JS, where plain objects are created right in shared memory, have a single owner thread and move between threads in O(1). Research prototype, alpha.*

Экспериментальный форк V8 для параллельного JavaScript без копий. `spawn(fn)` запускает функцию в другом потоке одной строкой. Объекты, созданные с директивой `'use region'` или литералами `#{}`, сразу лежат в общей памяти и переходят между потоками без копирования, сколько бы их ни было. У данных в каждый момент один владелец, и движок проверяет это при каждом обращении, поэтому гонок данных нет. Идея взята из Rust, удобство — из Go.

```js
// d8 --harmony-region-literals --module orders.js
const build = (from, to) => {
  'use region'; // каждый {} и [] ниже создаётся сразу в общей памяти
  using _ = new Region().enter();
  const orders = [];
  for (let i = from; i < to; i++) {
    orders.push({ id: i, customer: { name: 'customer ' + (i % 1000) }, items: [{ qty: 1 + (i % 3) }] });
  }
  return orders; // уезжает к вызывающему вместе с регионом, без копии
};

const parts = await Promise.all([0, 1, 2, 3].map((t) => spawn(build, t * 25_000, (t + 1) * 25_000)));
print(parts.flat().length); // 100000

// Каналы, как в Go: регион, отправленный в канал, переезжает без копии.
const jobs = new Channel(8);
const worker = spawn(async () => {
  let sum = 0;
  for await (const job of jobs) sum += job.payload.length;
  return sum;
});
await jobs.send(new Region().run(() => ({ id: 1, payload: [1, 2, 3] })));
jobs.close();
print('payload items:', await worker); // 3
```

Работает только в тестовой оболочке движка `d8`, в браузер и Node это не попадает.

## Против воркеров и tokio

Четыре рабочих потока, сборка V8 без внутренних проверок, лучший из пяти прогонов (`tests/bench-real.js`, `tests/tokio-bench`):

| Сценарий | `spawn` + регионы | воркеры + `postMessage` | Rust + tokio |
|---|---|---|---|
| Собрать 200 000 заказов в 4 потоках и прочитать в главном | 28 мс | 215 мс | 17 мс |
| 200 пачек по 1000 заказов: отдать, посчитать скидку, вернуть | 11 мс | 301 мс | 0,8 мс |
| Каталог из 100 000 товаров, 4 потока по миллиону чтений | 19 мс | 57 мс | 1,6 мс |

Против сегодняшних воркеров — в 3–27 раз быстрее, потому что ничего не копируется. До tokio пока в 2–14 раз: задача — сообщение другому изоляту V8, а обращения к объектам региона проверяют форму и владельца. Разбор — на странице [«Цифры»](https://tom4ikss.github.io/region-js/numbers.html#real).

## Что умеет

- **`spawn(fn, ...args)`** — функция в пуле воркеров одной строкой, около 1 мкс на задачу без внутренних проверок V8. Нужные переменные находит сам, регионы перемещает и возвращает, вложенные задачи заканчиваются раньше внешней, ошибки не теряются, есть отмена и `JoinSet`.
- **`'use region'` и литералы `#{}` / `#[]`.** Каждый `{}` и `[]` в функции с директивой создаётся сразу в регионе, прямо в машинном коде, без промежуточной копии. Директива — обычный синтаксис JS, TypeScript и линтеры её понимают.
- **Каналы** `new Channel(capacity)` с `send` / `recv` / `close` / `select`, `for await`, блокирующими версиями для воркеров и поиском дедлоков. **`RwLock`** для общих изменяемых данных.
- **Общие данные только для чтения.** `Region.share(data)`, как `Arc<T>`: все потоки читают одни объекты без копий и без билетов, память освобождает GC. Временная заморозка с правом разморозить: `freeze()` / `borrow()` / `thaw()`.
- **Регионы.** `new Region()`, `region.run(fn)` копирует готовый граф простых объектов, массивов, строк и типизированных массивов в общую кучу. Читать и писать может только владелец, остальные получают `OwnershipError`.
- **TypedArray** в регионе на полной скорости, с безопасным отсоединением view.
- **Воркеры напрямую.** `postMessage(msg, [region])` отдаёт регион своему воркеру без копии. Миллион узлов переезжает за ~0,1 мс против ~930 мс у structured clone.
- **`free()`** и `using`: освободить регион сразу, без ожидания GC, безопасно.
- **Песочница для VSCode:** типы, правила Biome и плагин ESLint, который ловит гонки владения до запуска.
- **Документация на русском** с примерами, у каждого из которых настоящий вывод d8, и микробенчмарками «плохо / хорошо».

## Как запустить

Нужны macOS или Linux, git, Python 3, около 10 ГБ места и терпение: V8 собирается долго.

```sh
scripts/setup.sh                     # depot_tools, V8 на нужном коммите, патч, сборка d8
v8-src/v8/out/release/d8 --harmony-regions --module tests/channels.js
```

Документация — на [сайте](https://tom4ikss.github.io/region-js/) или в `docs/index.html`, её можно открыть прямо из файла. Пересобрать с выводом примеров: `python3 docs/_build/build.py`.

Песочница: откройте папку `playground/` в VSCode, выполните `npm install`, запуск открытого файла — Cmd+Shift+B. Подробнее в `playground/README.md`.
